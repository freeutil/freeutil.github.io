글자 수 세기

공백 포함·제외 글자 수와 바이트를 계산합니다.

텍스트 입력
공백 포함0자0 byte
공백 제외0자0 byte

글자 수 세기 사용법

문장을 입력하거나 붙여넣으면 공백 포함 글자 수, 공백 제외 글자 수, UTF-8 기준 바이트 수를 실시간으로 보여줍니다.

  1. 텍스트를 입력창에 붙여넣습니다.
  2. 필요한 기준의 글자 수와 바이트를 확인합니다.
  3. 전체 복사 또는 전체 지우기를 사용합니다.

어떤 경우에 쓰나요?

자기소개서, 게시글, 광고 문구처럼 글자 수 제한이 있는 입력란을 작성할 때 편리합니다. 한글과 이모지는 UTF-8 인코딩 기준으로 바이트 수가 달라질 수 있습니다.
