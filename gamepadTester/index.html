게임 컨트롤러의 버튼과 스틱을 확인합니다.

컨트롤러를 연결하고 버튼을 눌러보세요.

연결한 뒤 컨트롤러의 아무 버튼이나 한 번 눌러주세요.

입력 상세

표준 매핑
게임패드 테스트 안내

브라우저가 인식한 게임패드의 입력을 실시간으로 표시합니다. 버튼을 누르면 해당 버튼이 강조되고, 스틱을 움직이면 방향과 축 값이 바뀝니다. 컨트롤러의 모델이나 연결 방식에 따라 버튼 번호와 표시 이름이 달라질 수 있습니다.

웹 브라우저의 Gamepad API는 연결된 컨트롤러를 버튼과 축의 배열로 읽습니다. 표준 매핑을 지원하는 패드는 A·B·X·Y, 숄더 버튼, 트리거, 스틱, 방향키가 일정한 번호로 전달되기 때문에 서로 다른 제조사의 패드도 기본적인 테스트가 가능합니다. 다만 호환 모드나 오래된 브라우저, 특수한 연결 드라이버에서는 표준 매핑이 적용되지 않아 실제 버튼 이름과 입력 번호가 다르게 보일 수 있습니다.

Xbox·PlayStation·Switch 계열은 같은 위치의 버튼에 붙은 이름이 서로 다릅니다. Xbox의 아래쪽 A는 Switch에서 B로 표시되고, PlayStation은 기호를 사용합니다. 이 페이지의 스타일 선택은 이런 차이를 보기 쉽게 바꾸는 기능이며, 연결된 하드웨어의 펌웨어나 브라우저가 전달하는 실제 버튼 번호 자체를 바꾸지는 않습니다. 따라서 특정 게임에서 키가 다르게 인식되면 이 화면의 버튼 표시와 입력 상세 번호를 함께 확인하는 것이 좋습니다.

스틱은 보통 가로축과 세로축을 -1부터 1 사이의 값으로 전달합니다. 중앙에 손을 놓아도 0에서 조금 벗어나는 현상은 센서 오차나 데드존 설정 때문에 생길 수 있으며, 손을 대지 않았는데 값이 계속 크게 움직이면 스틱 드리프트를 의심할 수 있습니다. 트리거는 눌린 정도를 0%부터 100%까지 연속적인 값으로 보내는 경우가 많아, 버튼처럼 눌림 여부만 확인하는 것과 다르게 미세한 입력도 살펴볼 수 있습니다.

USB 연결은 일반적으로 입력 지연과 배터리 걱정이 적고, Bluetooth는 선이 없어 편하지만 배터리 상태와 주변 전파 환경의 영향을 받을 수 있습니다. 같은 컨트롤러라도 운영체제와 브라우저에 따라 진동 기능이나 버튼 표준화 지원이 다를 수 있습니다. 진동 테스트 버튼이 비활성화되어 있다면 패드가 연결되지 않았거나 해당 브라우저·기기가 진동 API를 제공하지 않는 경우입니다. 이 도구는 게임 실행 없이 입력 상태를 확인하는 점검용 화면이므로, 문제가 생겼을 때 케이블·배터리·연결 모드·브라우저 인식 순서대로 확인하면 원인을 좁히기 쉽습니다.
