Vim 단축키 사용법

Vim은 현재 모드에 따라 같은 키의 동작이 달라집니다. Normal 모드에서 i를 누르면 Insert 모드로 들어가고, Esc로 다시 Normal 모드로 돌아옵니다.

Vim 버전과 기능 구성

Linux 배포판이나 macOS에 기본 설치된 Vim은 tiny, normal, huge 빌드 중 하나일 수 있습니다. 빌드에 따라 일부 플러그인·스크립트·외부 언어 연동 기능이 제한될 수 있습니다.

vim --version 또는 Vim 안에서 :version을 실행하면 현재 버전과 활성화된 기능을 확인할 수 있습니다.

vi와 Vim의 차이

Vim은 vi의 기본 조작과 명령을 대부분 이어받은 확장판입니다. Visual 모드, 다중 실행 취소, 문법 강조, 플러그인, 다양한 검색·편집 기능 등 Vim에 추가된 기능은 순수 vi나 호환 모드에서 사용할 수 없을 수 있습니다. 기본 이동·입력·저장 명령은 대체로 공통이지만, 사용하는 프로그램이 vi인지 Vim인지 먼저 확인하세요.

Vim의 모드와 편집 철학을 이해하는 방법

Vim을 처음 사용할 때 가장 낯선 점은 키를 누르면 바로 글자가 입력될 것이라는 기대가 깨진다는 것입니다. Vim은 입력 모드와 명령 모드를 분리합니다. Normal 모드에서는 글자를 입력하기보다 커서를 움직이고, 삭제하고, 복사하고, 명령을 조합합니다. Insert 모드에서 실제 텍스트를 입력한 뒤 Esc를 누르면 다시 Normal 모드로 돌아옵니다. 이 분리는 키보드의 거의 모든 글자를 편집 명령으로 사용할 수 있게 해 주며, 손을 홈 포지션에서 크게 움직이지 않고 긴 편집 작업을 처리하게 해 줍니다.

Vim의 명령은 동작과 대상을 조합하는 방식으로 확장됩니다. d는 삭제, y는 복사, c는 변경처럼 연산을 뜻하고, 뒤에 w나 $ 같은 이동 명령을 붙이면 단어 단위 또는 줄 끝까지 적용됩니다. 그래서 dw는 단어 삭제, y$는 줄 끝까지 복사처럼 읽을 수 있습니다. 처음에는 명령을 많이 외우기보다 h·j·k·l 이동, i·a 입력, dd 삭제, u 실행 취소, :w 저장, :q 종료처럼 자주 쓰는 핵심만 익히는 것이 좋습니다. 조합의 원리를 이해하면 새로운 명령을 만났을 때도 기능을 추측할 수 있습니다.

Vim은 오래된 터미널 환경에서도 사용할 수 있도록 설계된 편집기이지만, 오늘날에는 문법 강조·자동 완성·플러그인·버전 관리 연동 같은 기능을 더해 개발 환경으로 쓰이기도 합니다. 반면 서버에 설치된 Vim의 버전이나 tiny 빌드 여부에 따라 플러그인이 요구하는 기능이 없을 수 있습니다. 문제가 생기면 먼저 :version으로 빌드 구성을 확인하고, 현재 모드가 맞는지 Esc를 눌러 상태를 초기화한 뒤 명령을 다시 시도하세요. 설정 파일과 플러그인을 한꺼번에 바꾸기보다 하나씩 확인하면 원인을 찾기 쉽습니다.

Vim을 배울 때 자주 겪는 순간

Vim을 처음 사용하면 글자를 입력하려고 눌렀는데 명령이 실행되어 당황하기 쉽습니다. 이때는 Esc를 눌러 Normal 모드로 돌아온 뒤 i나 a를 눌러 Insert 모드에 들어가면 됩니다. 종료할 때도 파일을 저장했는지 먼저 생각하고 :w, :q, :wq, :q! 중 목적에 맞는 명령을 선택하세요. 실수했을 때 u로 되돌릴 수 있다는 점을 알면 여러 명령을 안전하게 시험할 수 있습니다. 서버나 복구 환경에서 Vim을 만났을 때 당황하지 않으려면 이동, 입력, 저장, 종료 네 가지 흐름만 먼저 익히고, 이후에 검색과 복사·붙여넣기를 추가하는 방식이 좋습니다.
