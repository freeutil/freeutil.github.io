운영체제를 바꾸면 하단 보조키 표기가 실제 키보드에 맞게 바뀝니다. Windows는 Ctrl·Win·Alt·Menu, macOS는 Control·Command·Option 기준으로 표시합니다. 입력 감지는 두 운영체제에서 공통으로 전달되는 물리 키 코드로 처리합니다.

브라우저는 키의 화면 글자보다 물리적인 위치에 가까운 code와 입력된 문자에 해당하는 key를 구분해 전달합니다. 그래서 QWERTY 키보드와 다른 배열을 사용하더라도 같은 위치의 키를 비교할 수 있습니다. 한글 입력기처럼 조합되는 문자는 완성된 글자보다 키 입력 이벤트 자체를 확인하는 것이 정확합니다.

여러 키를 동시에 누르는 게임이나 음악 작업에서는 키 롤오버 수가 중요합니다. 6키 롤오버, 무한 동시 입력 같은 표기는 키보드가 동시에 인식할 수 있는 입력 수를 뜻합니다. 이 테스트에서 여러 키를 차례로 눌러도, 동시에 눌렀을 때 일부가 빠지는지는 키보드의 USB 방식과 내부 회로에 따라 달라질 수 있습니다.

고스팅은 누르지 않은 키가 함께 입력되는 현상이고, 키 차단은 여러 키를 누를 때 특정 입력이 무시되는 현상입니다. 특히 오래된 멤브레인 키보드나 저가형 매트릭스 회로에서 조합에 따라 나타날 수 있습니다. 특정 키 조합에서만 문제가 반복되면 개별 스위치보다 회로의 동시 입력 한계를 의심해 볼 수 있습니다.

키캡 사이에 먼지나 음료 잔여물이 쌓이면 특정 키가 뻑뻑해지거나 눌린 채 남을 수 있습니다. 전원을 끄고 키보드를 뒤집어 가볍게 털어낸 뒤, 마른 브러시나 에어 블로어로 청소하세요. 액체를 키보드 안으로 직접 흘려 넣거나 강한 압축 공기를 가까이서 오래 분사하는 것은 피하는 것이 좋습니다.

키보드의 뿌리는 컴퓨터보다 앞선 타자기입니다. 초기 타자기는 키가 눌릴 때 금속 활자가 종이를 때리는 구조였고, 빠르게 입력할 때 인접한 활자대가 엉키는 문제가 있었습니다. QWERTY 배열은 이런 기계적 간섭을 줄이는 방향으로 자리 배치가 조정되면서 널리 퍼졌고, 오늘날에는 전자식 키보드에서도 익숙하다는 이유로 계속 사용되고 있습니다.

1980년대의 IBM Model M은 금속 스프링이 튀어 오르는 버클링 스프링 방식과 큰 타건음으로 유명해졌습니다. 이 시기 키보드는 단순한 입력 장치를 넘어 컴퓨터의 촉감과 소리를 결정하는 중요한 인터페이스가 되었습니다. 이후 멤브레인 키보드는 제조 비용과 두께를 낮추며 사무실과 가정에 빠르게 보급됐고, 노트북은 얇은 가위식 구조를 발전시켰습니다.

최근의 기계식 키보드는 스위치 종류와 작동 압력, 소리, 키캡 재질을 사용자가 고를 수 있다는 점에서 다시 인기를 얻었습니다. 같은 키보드라도 스위치의 접점 방식과 펌웨어에 따라 입력 속도와 동시 입력 처리 방식이 달라질 수 있습니다. 키보드 테스트는 이런 차이를 직접 확인하는 가장 간단한 방법입니다.
